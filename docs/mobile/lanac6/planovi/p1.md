### Izmena 2 — pozivnica se deli kao LINK (B5)

**Fajl:** `apps/mobile/src/app/(app)/pozivnice.tsx`, funkcija `CreateInviteSheet.submit`
(`:237–274`).

Posle uspešnog `create(...)`:

```ts
const link = inviteLinkUrl(result.code);   // helper je već uvezen na :33
```

- **`link !== null`** — Alert telo pokazuje **link** (ne goli kod), dugmad redom:
  1. `Podeli` → `Share.share({ message: link })` (`Share` iz `react-native`, core
     API, **nema nove zavisnosti**, `react-native@0.86.2`)
  2. `Kopiraj link` → `Clipboard.setStringAsync(link)` + potvrda „Pozivni link je
     kopiran u privremenu memoriju."
  3. `U redu`, `style: 'cancel'`
- **`link === null`** (`EXPO_PUBLIC_WEB_URL` nije podešen) — ostaje današnje
  ponašanje: telo pokazuje kod, dugme `Kopiraj kod`. Dodaj u telo rečenicu
  „Adresa web aplikacije nije podešena, pa se šalje samo kod."

Tekst linka u Alert telu skratiti nije potrebno — Alert prelama.

**LANAC UVOZA:** `lib/embed-url.ts:64 inviteLinkUrl` → `pozivnice.tsx:33` (uvoz)
→ **poziv u `submit`** → `CreateInviteSheet` montiran na `pozivnice.tsx:213` →

**ODLUKA: sesijsko pamćenje koda + akcija „Podeli" u redu pozivnice.**
(Ne samo share-sheet pri kreiranju.)

**Obrazloženje.** Server čuva samo `codeHash` (`invites.ts:54`) — kod posle

i rešava stvarni tok: admin napravi pozivnicu, pređe u WhatsApp, vrati se i shvati
da je poslao pogrešnoj osobi.

kredencijal, a njegovo trajno čuvanje na uređaju je veća površina napada nego što
pogodnost vredi. Nestaje sa procesom aplikacije. To je namerno i mora ostati
zapisano u docstring-u modula.

| Rizik | Simptom | Postupak |
