### Izmena 4 — temelj: apsolutna pozicija čvora + test

**Fajlovi:** **nov** `apps/mobile/src/lib/canvas-position.ts`; **nov**
`apps/mobile/src/lib/canvas-position.test.ts`.

Zamka je zapisana u `ZA-POPRAVKU.md` §9: ugnježden čvor u bazi ima **relativnu**
poziciju, a nova kartica (duplikat, grana, povezana misao) mora da sleti na
**apsolutnu**. Server to isto radi u `ideas.ts:148-164`, web u
`absoluteIdeaPosition`. Mobilni to nema, pa dobija jedan helper za oba tipa:

```ts
export type CanvasPoint = { x: number; y: number; complete: boolean };

/**
 * Apsolutna pozicija čvora = zbir sopstvene i svih roditeljskih (ideje i misli
 * ugnježdene čvorove čuvaju RELATIVNO). `complete: false` znači da lanac nije mogao
 * do kraja — roditelj nije u prosleđenoj listi (paginacija) — pa se rezultat NE
 * sme koristiti kao pozicija (vidi `ZA-POPRAVKU` Z5: pozicija se traži, ne pretpostavlja).
 */
export function absoluteNodePosition<T extends { _id: string; x: number; y: number }>(
  nodes: readonly T[],
  id: string,
  parentOf: (node: T) => string | undefined,
): CanvasPoint
```

Petlja ide sa `Set` viđenih i tvrdim ograničenjem od 512 nivoa (isto kao server) —
ciklus u podacima ne sme da zamrzne ekran. Nepoznat `id` → `{x:0, y:0, complete:false}`.

**Test** (`canvas-position.test.ts`, vitest projekat `mobile`): top-level čvor vraća
svoje koordinate i `complete:true` · jedan nivo ugnježdenja se sabira · dva nivoa se
sabiraju · roditelj koji nije u listi daje `complete:false` · ciklus se prekida i ne
visi · nepoznat id daje `complete:false`.

**LANAC UVOZA:** `lib/canvas-position.ts` → `idea-actions-sheet.tsx` (izmene 5 i 6)
→ `ideje.tsx:243` / `ideja/[id].tsx:273`; → `misli.tsx` (izmena 7). Plus test.

   kao do sada; to nije u spisku ove faze. (Posledica: `IdeaCreateSheet` se na listi i

6. **Neću dirati `pretraga.tsx` ni `MemberSearchInput`.** Prvi je izvor obrasca za nov
   primitiv, ali je njegov ekran van opsega; drugi je polje **u sheet-u** (kartica sa
