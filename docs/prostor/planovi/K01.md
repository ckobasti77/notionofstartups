## 1. Dozvole (P1)

### 1.1 Pojmovi
- **Član** — prolazi `requireStartupMember` (`lib/auth.ts:40-61`): aktivan profil, aktivno članstvo, startup nije arhiviran. `startupId` se uvek čita iz dokumenta, ne iz argumenta.
- **Autor** — `pages.createdByProfileId`, `ideaNodes.authorProfileId`, `contentContributions.authorProfileId`.
- **Vlasnik** — `startups.createdByProfileId`. **Admin** — `profiles.role === "admin"`. **Menadžer** = vlasnik ∨ admin.
- **X** = nečlan, uklonjen član (`startupMembers.archivedAt`), arhiviran profil (`profiles.archivedAt`), član drugog startupa → baca se pre bilo kog čitanja.
- **Zaključano** — `pages.lockedAt != null`. Oblasti i ideje se ne zaključavaju.

Algoritam `recordRevision`:
1. `before` i `after` jednaki → `null`.
2. `latest = latestRevision(key)`; ako `null` → upiši **baznu** (`kind: "baseline"`, `before`, `authorProfileId = baseline.authorProfileId`, `createdAt = updatedAt = baseline.at`).
   - Stranica: autor = `page.createdByProfileId` kad je `page.revision === 0`, inače `null`; `at = page.updatedAt`.
   - Ideja: autor = `authorProfileId` kad je `updatedAt === createdAt`, inače `null`. Oblast: `null`, `at = areaBody?.updatedAt ?? now`.
3. Ako `latest.kind === "edit"` ∧ `latest.authorProfileId === actor` ∧ `now - latest.updatedAt < REVISION_MERGE_WINDOW_MS` → `patch(latest, { title, content, instructions, targetRevision, updatedAt: now })`.
4. Inače `insert({ kind: "edit", ...after, authorProfileId: actor, createdAt: now, updatedAt: now })`.

Mutacija sme da čita sat; upiti ne. „Vrati" (`restore`) se nikad ne spaja. Obrezivanja nema.
