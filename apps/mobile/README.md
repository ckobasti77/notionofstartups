# Mobilna aplikacija

Ovde će živeti Expo (React Native) aplikacija — drugi klijent nad istim Convex
backendom iz `packages/backend`. Postavka okruženja i scaffold koraci:
[docs/mobile/01-SETUP-WINDOWS.md](../../docs/mobile/01-SETUP-WINDOWS.md).

Folder je namerno bez `package.json` dok projekat ne bude kreiran — npm
workspaces preskače direktorijume bez manifesta.
